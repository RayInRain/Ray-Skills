# 技能目录

当前暂无可安装技能。根目录原有的 DFMEA、FMEDA、FTA、WCA 等长文已归入参考资料，不计为已完成的 skill。

新增技能采用以下结构（按需创建子目录）：

```text
skills/<skill-name>/
  SKILL.md
  references/
  scripts/
  assets/
```

每个 `SKILL.md` 包含 YAML 元数据 `name`、`description`，正文说明适用情境、必需输入、操作步骤、输出和验证方式。详细规则见 [收纳规范](../CONTRIBUTING.md)。

有技能入库后，在此索引记录名称、领域、用途、路径、来源、运行依赖和验证状态。
