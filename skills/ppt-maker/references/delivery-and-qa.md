# 制作交接与质量检查

## 先确定真实交付终点

用户只要内容、讲稿或页面方案时，完成该产物即可。用户要实际文件时，尽早检查当前可用的制作技能、工具、模板和输入；能力限制影响目标时及时说明，继续完成可用部分。不要直到最后才把实际 PPT 请求换成外部工具推荐。

本 skill 定义内容与设计协议，不内置 PPTX、PDF 或 HTML 生成器。可调用的制作技能和工具负责文件实现；不存在时不臆造工具名、命令或结果。用户要求交给另一 Agent 时，产物是自足交接包；实际创建任务、发送消息或上传仍遵循当前授权和环境能力。

## 交接包的最小内容

简单任务可集中在一份 Markdown，复杂任务引用同目录文件；不复制多个可独立修改的正文版本。

| 项目 | 内容 |
|---|---|
| 任务说明 | 受众、目的、时长／页数、目标格式、语言、品牌、不可改项 |
| 内容主稿 | 当前版本、稳定页面标识和顺序、逐页完整文案、需要时的讲稿 |
| 视觉设计 | 全局视觉规则和各页表达形式、焦点、阅读顺序、构图与约束 |
| 数据与素材 | 证据定位、计算口径、模板与资源路径、素材可用状态 |
| 模板契约 | 默认英搏尔或用户明确覆盖项；实际源文件与哈希、源页／布局映射、固定品牌对象、内容安全区及可编辑对象 |
| 执行任务 | 已完成事项、下一动作、需要试制的代表页、验收点与返修边界 |
| 当前状态 | 设计是否就绪、用户确认范围、实际文件与视觉检查状态、阻塞项 |

文件包使用能随包移动的相对路径；跨环境接收者不能访问的资源列为缺项。模板缺失但普通文字设计仍可推进时，先完成可用方案；未经实际母版检查，不宣称完成源版式映射。

默认英搏尔任务执行 [品牌协作契约](brand-contract.md)，交接中写明必须加载的制作技能和资源。不能只给另一 Agent 一个“请沿用公司风格”的口号，也不能只交全文让它自行把文字均分到每页。接收方应能直接得知每页的结论、图形语义、上屏文字和固定品牌边界。

讲稿应进入目标格式的备注区或独立讲稿文件，制作指令留在交接文件。受众不应在正式页面上看到内部检查状态、工具名称或操作说明；必要的来源、假设和待验证性质可作为内容的一部分呈现。

## 两端职责与改动范围

| 角色 | 负责 | 可自主调整 | 实质变化如何处理 |
|---|---|---|---|
| 内容与设计方 | 事实、结构、逐页主张、表达形式、焦点与构图 | 在授权范围内优化未确认内容与设计 | 更新主稿、版本与依赖，必要时提出决定事项 |
| 制作方 | 模板映射、原生对象、素材、实际排版、渲染检查与导出 | 保持语义的换行、间距、尺寸、对齐、适当裁切 | 提出受影响页的具体修订，回写主稿；不静默改变结论、数据或必需内容 |

内容溢出时，制作方先处理局部排版，再考虑不改变含义的简化和已允许的替代布局。需要删重要信息、改变对比口径、增加或减少受限页数时，返回相应设计决定。未受影响页面保持稳定，不借返修重写整套内容。

## 代表页到全稿

执行 [页面设计中的试制规则](page-design.md)，用实际内容选择必要代表页；普通页与最复杂页面应覆盖主要风险。试制结果写明使用模板、实际画面问题和采取的调整。表达不成立回设计环节，排版偏差由制作端修正。

代表页可用后完成全稿，再检查全部生成页面。不同格式可以使用不同实现，但事实、顺序和关系一致。PPTX 要求可编辑时使用原生文本、图表、形状及连接线；整页图片不能代替。嵌入 SVG 或位图时如实说明对象级与内部节点级编辑的区别。

查看最终导出文件重新渲染的页面，不能只看导出前的内存预览。源模板、导入版本和最终导出分别比较固定品牌层；原文件未被改动不能单独证明成品保真。代表页效果按当前协作约定给用户讨论，用户已授权一轮完成时保留 AI 验收状态。

## 外部工具交接（仅在选定该路径时）

不默认推荐收费工具或强制输出三份提示词。选择真实可用且符合用户偏好的一个工具；需要比较当下功能或价格时再核实，无法核实时说明限制。

根据当前交接包写一份可直接使用的执行提示词，包含：输入文件及版本、目标格式、页序和内容保持要求、品牌依据、逐页设计的确定项与弹性、素材缺口、真实数据与可编辑性要求、试制和最终检查。只写实际已提供的附件；不要宣称“已上传模板”而模板尚不存在。

若只能提供提示词，就明确文件制作尚未执行。未获上传或发送授权时交付本地材料，不自动把用户内容交给外部服务。

## 按产物验收

| 对象 | 检查 |
|---|---|
| 内容与结构 | 回应目标与受众、页序与篇幅合适、结论可支撑、无无依据新增事实 |
| 共创过程 | 用户的观点、真实例子及方向得到体现；确认对应实际展示的内容；自行假设未写成用户已确认 |
| 数据 | 数字、总量、比例、公式、分母、单位、期间与图表标签一致；拟议不写成实绩 |
| 页面设计 | 表达形式适合内容，焦点与阅读顺序具体，最终内容有空间，素材与布局匹配 |
| 整套风格 | 字体、色彩、对齐与品牌一致；密度和版式变化有内容理由 |
| 模板保真 | 成品沿用源母版／布局及固定品牌对象；按已记录的用户明确覆盖范围检查，其余 Logo、页眉页脚、版权和原版感谢页没有遗漏、重画或位移 |
| 讲稿 | 与页面一致，状态词和数字一致；篇幅匹配时长，未试讲则时长仅为估计 |
| 实际文件 | 文件存在并可打开或渲染；逐页检查重叠、裁切、换行、页码、图表和资源缺失 |
| 可编辑性 | 需要编辑的文字、数据和关系对象确实满足要求，不仅是可选择的一张图片 |
| 交接包 | 主稿全文、版本、数据与素材引用可访问，未完成项和下一动作明确 |

验收记录采用具体问题、采取的修正和仍存影响，不用缺少证据的“设计 9 分”替代查看。AI 可修的问题先自行修；需用户决定的取舍集中说明。

视觉审阅要回答：不读讲稿能否理解关键关系；第一眼焦点是否明确；信息是否只是分栏堆字；关系图的箭头和分组是否正确；层级与留白是否支持阅读；素材是否提供真实信息；是否保持公司气质。任一适用项失败就返回设计或排版修正。纯标题／引言页不强配图，但多页关系内容全部是文字框时必须重新检查表达选择。

若制作工具对原模板继承元素支持不足，或校验器只检查页内对象而误判含继承内容的页面，记录具体诊断与实际渲染证据。不得添加隐藏对象骗过检测、栅格化整页或删除品牌页来换取“通过”；在能力得到验证前不宣称完整成品通过。

## 交付措辞与完成状态

- **文字方案完成**：完整内容和设计可交接；没有实际页面时写明视觉待验证。
- **制作交接完成**：接收方有足够材料开始制作；不等于 PPTX 已生成，也不等于已经发送给接收方。
- **文件已导出**：实际导出成功；还需分别报告内容完整性、视觉检查和可编辑性。
- **成品已验证**：只在要求的内容和文件检查实际完成后使用。仅部分检查通过时列明范围。

尚有必需数据、素材或会影响阅读的问题时，交付标为草稿／部分完成，并给出具体缺项。导出成功但无法渲染时，写明视觉未验证；不要给出不存在的文件链接，也不要用“可直接交付”掩盖占位内容。

最后提供用户实际可访问的产物路径或完整文本、完成范围、必要未完成项和恢复入口。没有问题时不额外制造风险清单。
