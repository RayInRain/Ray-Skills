# 从车型追溯报价：通用案例

此案例只说明查询方法，示例标识均为虚构，不对应真实客户或产品。

用户要查“车型 A 的电机控制器价格”。在报价明细按“物料名称”搜索车型 A，结果主要是电源和工装，不能据此认定没有控制器。

改用全局搜索车型 A，找到同客户、同部件的样机申请。样机申请的项目标题、技术备注和技术方案确认可能分别出现不同车型或产品编码。例如标题写“车型 A 电控”，备注写“车型 B，产品代码 X-001”，技术方案确认写“代码 X-003”。先记录这些差异，不提前选一个为准。

回到报价明细，明确将搜索字段切换为“英搏尔物料代码”，分别搜索 X-001、X-003；若有客户零件号，还可用“客户产品代码（图号）”交叉查询。打开命中的每一条明细，比对客户、完整物料名称、规格、图号、报价用途、价格、审批状态与执行期。

如果报价对应 X-001，仍不能仅凭样机申请标题将它认定为车型 A 的量产价。报告应写明可以确认的关联、样机/量产价格性质，以及型号和编码冲突。样机申请单价为 0 或空值时，不据此推断免费或成交价。
