# Codex 内置图片工具 配图提示词

用于 Codex 环境下为本 skill 生成 PPT 配图。提示词只负责定基调,不要写成长篇说明。先判断图片落位和比例,再选择类型。

先读 `visual-planning.md` 选择表达方式，不设置 SVG、原生图形或图片的固定优先级。关系、流程和架构可在合适时用图形，也可用主题图片或图文组合增强表达。按实际内容使用下文提示词；图片中的关系必须核对，精确数据不得由模型猜测。生成或编辑图片时读 `codex-image-generation.md` 执行调用、保存和插入。以下为提示词参考，不代表工具已执行。

## 通用规则

- 风格必须服务于实际主题、主体、受众和页面用途；示例只提供结构，不能把无关的电驱、汽车或科技元素套入其他主题。
- 同组图片的媒介、色彩和构图尺度应协调；主动安排对应主题的图片丰富页面，与图形和留白搭配，避免全稿仅有文字和线框，也不加入无关图片。

- 先判断当前 deck 风格：默认风格 C = 英搏尔品牌风；用户明确选择时才使用风格 A = 电子杂志 × 电子墨水，或风格 B = 瑞士国际主义 / Swiss Style
- 风格 A 基调:电子杂志 × 电子墨水,克制、真实、留白充足,适合横向网页 PPT
- 风格 B 基调:Swiss International Typographic Style,12/16 列网格、Helvetica/Inter 气质、单一高饱和 accent、直角纯色、发丝线、极大留白
- 信息图、图表、截图再设计中的文字语言必须跟随用户语言:中文 deck 用中文,英文 deck 用英文
- 不生成卡通、3D、霓虹科技感、SaaS 模板感、过度装饰或假 logo
- 图片要给标题或正文留出可叠加空间,不要满屏堆细节
- 同一页或同一组图片必须使用同一比例、同一视觉缩放、同一边距密度
- 配图是嵌入 PPT 的素材,不是一张独立 slide:不要生成页眉、页脚、页码、标题栏、角标、署名、装饰边框或 slide chrome
- 生成后保存到 `images/`,命名为 `{页号}-{语义}.{ext}`

## 比例选择

下表 CSS 类属于 A/B 模板。风格 C 采用同样的比例建议，但使用品牌模板现有类或局部样式，不复制 A/B 类名。

| 用途 | 推荐比例 | HTML 落位 |
|------|---------|-----------|
| 章节封面 / 全屏主视觉 | 16:9 | `.frame-img.r-16x9` 或 hero 背景参考 |
| 瑞士风顶部横幅 / Image Hero | 16:9 或 21:9 | P22 顶图 cover / `.frame-img.r-21x9` |
| 左文右图主图 | 16:10 或 4:3 | `.frame-img.r-16x10` / `.frame-img.r-4x3` |
| 信息图 / 系统关系图 | 16:9 或 16:10 | 原始截图用 `.fit-contain`;按槽位重生成则用 `.frame-img.r-16x9` / `.frame-img.r-16x10` 铺满 |
| 截图再设计 / UI 情景图 | 16:10 或 21:9 | 原始截图用 `.fit-contain`;重生成到 S15/S16 时用 `.frame-img.r-21x9` 铺满 |
| 图文混排小图 | 3:2 或 3:4 | `.frame-img.r-3x2` / `.frame-img.r-3x4` |
| 图片网格 | 统一横图 | `.frame-img.h-22` / `.frame-img.h-26` |
| 小型面板组 | 统一横图 | `.frame-img.h-16` / `.frame-img.h-18` |

信息图和截图再设计如果来自不可控原始素材,优先用 `fit-contain`,避免文字被裁切;如果是 Codex 内置图片工具 按槽位重新生成,必须生成同槽位比例并铺满容器,不要让小图漂在白框里。纪实照片优先用默认 `cover`,保持画面张力。

## 图片标准化策略

### A. 先选目标槽位

不要先生成图片再硬塞进页面。先决定图片落位:

1. 主视觉:16:9
2. 左文右图:16:10 或 4:3
3. 信息图/截图再设计:16:9 或 16:10,并使用 `fit-contain`
4. 多图网格/面板组:统一高度类,同一组内禁止混用高度

### B. 用户原始图片/截图的处理

原始截图比例通常不可控,不要直接作为最终视觉标准。按下面顺序处理:

1. 默认 C 保真截图直接放入品牌内容区，通过页面留边、等比缩放和标注组织，不加 A/B 装饰背景。明确选择 A/B 时才读 `screenshot-framing.md` 采用对应背景与框架；需要改变图片像素内容时使用当前图片编辑工具。
2. 如果原图比例接近目标槽位，直接按当前模板的图片区域使用 `cover` 或 `contain`；`.frame-img` 等类仅在所选 HTML 模板实际提供时使用。
3. 如果一张 UI 图被拉成巨长条,拆成 2-3 张同尺寸局部面板;每个面板使用同一高度类
4. 如果原图过高、过窄、过长且无法通过适配解决,再用"截图再设计 / UI 情景图"重新生成到目标比例
5. 如果必须保留原图,用 `fit-contain` 放进统一 frame,接受留白,不要裁掉关键文字

### C. 生成提示词后缀

每个配图提示词最后都补一句规格约束:

```text
输出必须是[16:9/16:10/4:3/3:2]横向构图,主体居中但保留边距,画面密度中等,与同组图片保持相同视觉缩放和边距。只保留核心图形/画面本身,不要生成页眉、页脚、标题、页码、角标、署名、装饰边框、超长条、竖图或不规则比例。
```

同一页需要多张图时,补一句:

```text
这是一组图片中的一张,请保持与同组图片相同的画面比例、元素大小、边距、线条粗细和标注密度。
```

## 风格 C：英搏尔品牌配图（默认）

- 使用品牌蓝 `#005687`、少量品牌红 `#E10600` 和白/浅灰背景，专业、简洁、留白充足；照片保留自然色彩，不必把物体全部染成蓝色。
- 品牌封面和感谢页优先使用内置天空、园区、Logo 与二维码素材。生成图主要补充正文案例和概念说明。
- 不让模型生成 Logo、二维码、真实产品型号、未经提供的参数或公司业绩。需要精确文字时，在 HTML/PPTX 中另外添加可编辑标签。
- 真实产品展示使用用户提供的照片；抽象构想、未来场景或示意产品明确标为概念示意。

### C1：技术概念配图

```text
为英搏尔品牌技术汇报生成一张[主题]概念配图。白色与浅灰背景，以品牌蓝 #005687 为主、少量品牌红 #E10600 强调，专业工业设计气质，清晰克制、留白充足。[16:9/16:10/4:3]横向构图，主体完整并位于安全区。仅生成画面，不含文字、Logo、二维码、水印、页眉页脚或幻灯片边框，不冒充真实产品照片。
```

### C2：行业应用场景

```text
生成用于英搏尔品牌演示的[新能源汽车/工业制造/能源应用等具体场景]概念摄影配图。[主体与环境]，自然光，真实材质，简洁干净的环境，冷静专业的视觉，与蓝白品牌页面协调。横向[16:9/4:3]，关键主体完整，按页面落位留出适当空白。不含公司标识、型号、文字、水印或虚构业绩数据，不表示英搏尔真实现场。
```

### C3：透明产品概念素材

```text
生成[用户指定产品概念]的独立概念素材，专业工业视觉，主体完整、边缘清晰，无背景、无文字、无Logo、无参数标注，为英搏尔品牌PPT正文配图使用。不表示真实在售产品。
```

此项同时设置工具参数 `transparent_background: true`，不能只在提示词中说“透明”。

### C4：原图编辑

```text
编辑所附图片：仅[明确要修改的内容]。保留[产品形状、结构、现有文字、位置等必须保留项]，不新增Logo、型号或技术细节。整体色彩与英搏尔蓝白品牌页面协调，输出适合[目标比例]槽位的构图，不裁掉关键主体。
```

先查看原图并传入实际图片引用。要求真实数据/文字完全准确时优先保留原图，用页面布局处理留边，不依赖模型重画来保证精确。

## 风格 B:瑞士国际主义配图规则

当 deck 选择 `assets/template-swiss.html` / `layouts-swiss.md` 时,优先使用下面这组提示词。它们和 Codex 内置图片工具 配套,目标是生成能直接放进原始登记版式的图片槽位,尤其是 S22 顶部横幅、S15/S16 多图网格。

### Swiss 配图硬规则

- 视觉锚点:International Typographic Style / Swiss modernism / Helvetica / Josef Müller-Brockmann / Massimo Vignelli
- 构图:严格 12/16 列网格、非对称留白、左对齐、发丝线、直角模块
- 色彩:只使用黑、白、灰和**一个**主题 accent(默认 IKB 蓝;如果用户选柠檬黄/绿/安全橙,就替换为对应 accent)
- 禁止:渐变、阴影、圆角、玻璃拟态、霓虹、3D、卡通、SaaS 模板感、伪 logo、装饰边框
- 图片内部不要生成 PPT 外壳:不要页眉、页脚、页码、标题栏、角标、署名、外框
- UI / 信息图文字必须短,保持中文/英文语言一致;真实照片尽量不要带文字
- 先确定版式槽位再生成图片:单张大图用 `s22-hero-21x9`;多图格用 `s15-grid-21x9` 或 `s16-brief-21x9`
- 21:9 图片必须让核心主体落在中央 70% 安全区,四周留白;不要把人脸、关键节点或 UI 文字贴边

