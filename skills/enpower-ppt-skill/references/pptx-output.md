# PPTX 输出模式

目标格式以用户本次请求及已确认交接包为准：未指定时按 `delivery-format.md` 询问仅 PPT、仅 HTML 或两者都要；明确只要一种时仅制作该格式。用户只要求大纲、文字设计或交接包时不自动制作文件。本页仅在目标包含 PPTX 时执行。

## 英搏尔 Enpower 模板

以下是默认 C 风格的 PPTX 工作流。先读 [公司模板与共创契约](enpower-contract.md)，视觉来源只使用 `assets/empower/reference.pptx`。不要把 HTML 页面截图粘贴进 PowerPoint，也不要混入电子杂志风、瑞士风或 Codex Grid。用户明确选择 A/B 时才转入对应风格制作，并如实说明不属于英搏尔模板成品；不能因内容是数据或技术自行切换。

1. 使用 Presentations Skill 的 template-following 工作流。
2. 将 `assets/empower/reference.pptx` 设为 `TEMPLATE_PPTX`。
3. 检查全部 8 张源页及其继承的 slideLayout、slideMaster、theme、媒体与字体，建立 `template-frame-map.json`。只检查 slideN.xml 会漏掉固定品牌对象。源第 5 页是使用须知，第 7/8 页是 ICON 库，不自动作为业务页交付。
4. 封面优先继承源第 1 页；目录继承第 2 页；通用正文继承第 3 页；图表继承第 6 页；结束页继承第 4 页。
   使用图表页前检查导入导出后的图表对象、数据系列和嵌入工作簿是否仍在，不能只验证背景与 Logo。若转换器丢失示例图表，在相同原品牌布局的内容区按已核实业务数据创建新的原生图表并验证；不得把丢失数据当成正常空白页，也不得用截图代替需要可编辑的图表。
5. 区分固定品牌层与正文设计区：品牌对象、母版、布局、主题、Logo、页脚和品牌素材保留原样。测量并登记正文区域后，可在该区域编辑业务占位内容、添加原生图表、文本、形状与连接线，记录新增对象及范围。不能把品牌保护解释为只能向原有文本框堆字，也不能为排版方便重建品牌层。
6. 默认通过 Presentations 的 `@oai/artifact-tool` 导入、编辑、渲染和导出 `.pptx`。可选采用 `integrated-production.md` 中经实测保真的 PPT Master 原稿编辑方式；其原生依赖按该说明使用。不自行用 python-pptx 从空白重建母版。
7. 用真实内容先试制一般正文和最复杂页面，按共创节点展示效果并落实反馈，再完成全稿。重新打开/渲染最终导出文件，逐页检查重叠、裁切、换行、空占位符、Logo、页脚和可编辑对象；品牌保真按契约独立核验。
8. **每份正式英搏尔 deck 必须以感谢页收尾**：`THANKS` + `驱动智慧出行 / 赋能美好生活` + 左下公众号二维码 + 右下园区建筑。除非用户明确要求删除，否则不得省略。
9. 交付本次约定的目标格式；未指定时先按 `delivery-format.md` 明确选项。两种格式内容一致，各自保留品牌规则，不用整页截图相互转换。

## 环境预检

在实际制作前，可运行 `scripts/roundtrip-empower-template.mjs` 验证当前演示文稿运行时能导入、渲染并重新导出母版。该脚本不负责填充业务内容，成功也不证明继承对象、字体或品牌素材被正确保留；必须比较源模板与输出。默认 C 不得调用 `scripts/build-empower-cover-pptx.mjs` 的空白重建路线替代母版复用，也不得将其结果标成模板保真通过。

工具不能保留原母版时，保留主稿、设计说明和具体能力限制；可验证其他实际支持母版的制作能力，但不退回空白仿制或整页截图并宣称完成。不要直接修改 skill 中的母版资产。

## 内容输入

已有 `ppt-maker` 确认的主稿时直接接收；只有未经策划的 Markdown、Word、表格或旧 PPT 才先按共创节点形成逐页内容计划，再选择源版式。文字放不下时先压缩不改变含义的文案或按已约定篇幅拆页，禁止缩小到源模板规定的最小字号以下。

## Codex 生成配图

先按 `visual-planning.md` 规划页面视觉；关系、架构、流程按内容与效果选择原生图形、SVG、图片或组合，不设固定优先级。主动加入对应主题的产品、场景、案例或概念图片丰富页面，并如实说明 SVG/位图的编辑限制。确需生成或编辑图片时，按 `codex-image-generation.md` 调用内置图片工具，并按 `image-prompts.md` 的默认 C 风格组织提示词。先将生成图片保存到演示目录的 `images/`，再通过 Presentations 工作流嵌入为独立图片对象。保留母版、品牌素材和可编辑标题/正文/图表；位图内部内容不宣称可编辑。渲染实际插入图片的页面，检查裁切、遮挡、清晰度和品牌一致性。

## 布局与调整上限

按 `visual-planning.md` 保持高端、优雅、清晰的布局。简单位置修正同一问题最多 3 次，仍未解决则保留最可读版本，记录页码、元素、尝试与影响，继续其他页并在交付时统一报告。最终视觉检查不重置次数，不将未解决问题标记为通过。

## 素材、分层与工具选择

制作前读取 `integrated-production.md`，统一素材清单、图片与可编辑对象分层、工具预检和最终文件验证；仅在当前安装版本实际支持且验证通过后使用可选原稿编辑方式。
