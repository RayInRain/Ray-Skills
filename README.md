## 后续如何收纳 skill

统一使用 `skills/<skill-name>/SKILL.md`，目录名采用小写英文与连字符。按领域分类放在目录索引中，不增加多层安装路径。技能依赖的脚本、参考材料和模板放在其自身目录内，确保单独复制该目录也能使用。

新增或迁入前阅读 [收纳规范](CONTRIBUTING.md)。当前没有安装脚本；将来安装时复制某个完整技能目录到目标工具支持的 skills 路径。仓库作为源文件，安装目录作为部署副本。

下一步按清单迁入本机已有技能，区分自编、修改过的第三方、原样第三方和插件托管技能，记录来源、版本与许可。同名技能比较内容后再确定保留方式。
